$ pinwatch --help

ASUS Astral GPU connector telemetry; read-only CLI and desktop companion

Usage: pinwatch [OPTIONS] <COMMAND>

Commands:
  devices  Enumerate GPU identities, sensor support, adapters, and queryable control ranges
  status   One snapshot from the daemon, or read-only hardware access if it is absent
  watch    Continuous readings. --json emits flushed NDJSON, no ANSI or stdout diagnostics
  notify   Relay read-only daemon events to the desktop session's standard D-Bus notifier
  help     Print this message or the help of the given subcommand(s)

Options:
      --config <CONFIG>              Local fallback configuration; default: /etc/pinwatch/pinwatch.toml if present
      --socket <SOCKET>              [default: /run/pinwatch/pinwatch.sock]
      --uuid <UUID>
      --index <INDEX>
      --simulate <SIMULATE>          Force local simulation from a fixture, bypassing the daemon
      --adapter <ADAPTER>            PCI-local adapter override for fallback (requires a single selected GPU)
      --lock-dir <LOCK_DIR>
      --nvml-library <NVML_LIBRARY>
  -h, --help                         Print help
  -V, --version                      Print version
